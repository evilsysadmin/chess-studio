# Chess Football player art

Runtime player art is deterministic vector 2D. The committed SVG atlases are generated by
`scripts/art/chess_football_sprite_forge.py` and sliced exclusively through `manifest.json`.

Contract borrowed from Pawn Slug Sprite Forge:
- fixed 112×144 cells, 8 frames per animation;
- canonical footline at y=126 and one display scale across both teams;
- no text, numbering, UI or worksheet decoration inside runtime cells;
- animation rows are explicit in the manifest: idle, run, sprint, pass, shoot, tackle, celebrate;
- runtime consumes the manifest instead of hardcoded atlas coordinates;
- the forge is deterministic and CI verifies committed bytes against regenerated output.

The SVG is the current lightweight POC delivery format. If the art grows materially, promote the
same logical contract to immutable R2 assets rather than growing Git with opaque binaries.
