# v16.6v — dependency/runtime hardening

- PyJWT pinned to 2.13.0 and local venv path normalized to an absolute path.
- `make deps-status` shows the requirements pin, active venv PyJWT version and Trivy version.
- backend install uses `pip install --upgrade` when requirements change.
- Trivy bootstrap updated to 0.74.0 and checks/upgrades an existing local binary.
- Trivy scans use `--skip-version-check` to avoid noisy update notices after the pinned tool is installed.
- Backend Docker image runs as an unprivileged `chess` user and has a Dockerfile HEALTHCHECK.
- Frontend nginx runs as the `nginx` user on port 8080 and has a Dockerfile HEALTHCHECK.
- docker-compose maps the frontend host port to container port 8080.
- npm audit report now names HIGH/MEDIUM/LOW packages/advisories instead of only printing counts.
