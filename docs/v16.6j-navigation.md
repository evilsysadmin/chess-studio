# v16.6j — navegación atrás real

- ESC y clic derecho vuelven a la vista anterior de la app.
- Los botones «Volver» de las pantallas usan la misma pila.
- Los modales siguen cerrándose antes que la pantalla padre.
- Si no existe una vista anterior válida, el fallback es el menú.
- La parte reconstruible del historial se guarda en sessionStorage, así que un refresh no destruye la navegación anterior.
- Las vistas efímeras (partida/replay) no se restauran tras refresh para evitar estados zombis.
