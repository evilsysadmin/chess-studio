# v16.6cr · Combat Chess campaign operational flow

La campaña se presenta ahora como una operación por fases:

1. Objetivo
2. Briefing
3. Despliegue
4. Combate

## Regla de integridad

Los encuentros de campaña activan `requireDeploymentConfirmation`.

- Entrar en la preparación abre la Mesa de Guerra automáticamente.
- Cerrar la mesa no confirma nada.
- La fuerza sólo se confirma con el CTA explícito del deployment.
- Una formación incompleta o con bajas pendientes no puede confirmarse.
- Cualquier cambio posterior relevante de composición/loadout invalida la confirmación.
- `startBattle()` mantiene un segundo guard interno: no existe un bypass programático desde la UI.

## Jerarquía visual

Mapa: elegir objetivo.

Briefing: decidir inteligencia y pasar a despliegue.

Preparación: una sola pregunta dominante, «¿qué falta para estar listos?», con:

- siguiente paso;
- desplegados / banquillo / bajas / XP;
- estado de fuerza;
- CTA principal único.

Tras confirmar la fuerza aparece por primera vez el CTA `INICIAR COMBATE`.
Los ajustes secundarios y la hoja de servicio quedan detrás de un `details` para reducir ruido.
