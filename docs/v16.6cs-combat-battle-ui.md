# v16.6cs · Combat Chess battle UI

Combat Chess usa durante la batalla la misma jerarquía visual que una partida
normal o de torneo:

- reproductor en el rail izquierdo;
- tablero en el centro;
- rail derecho para información contextual;
- estado de turno y controles en las mismas posiciones generales.

El rail derecho no contiene Game Chat, comentarios sarcásticos de CPU ni
reacciones de público. Se dedica a datos propios de Combat Chess: efectivos en
pie, nivel total, XP pendiente y registro de capturas. La explicación de Fuerza,
Velocidad y niveles queda plegada bajo `Ayuda rápida`.

El reproductor global sólo se oculta mientras `CombatBattleView` está activo;
setup, campaña y despliegue siguen usando el dock global habitual.

Terminología de despliegue: el CTA obligatorio pasa a llamarse
`CONFIRMAR DESPLIEGUE`.
