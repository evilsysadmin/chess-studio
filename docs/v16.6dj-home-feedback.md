# v16.6dj · Home simple + feedback operativo

## Objetivo

Reducir saturación para jugadores nuevos y cerrar el circuito de feedback sin depender de correo ni servicios externos.

## Home de campaña

La portada de campaña muestra primero una explicación de una línea y una única acción principal: **Iniciar Operación La Torre**. Los detalles de reglas, ejército/expediente y operaciones pasadas están disponibles en paneles plegables.

## Feedback

La Home expone un botón `Dar feedback`. El formulario pide sólo categoría y texto. `POST /api/feedback` exige sesión válida y guarda usuario, categoría, contexto, mensaje, fecha y estado.

El Panel de admin consume `GET /api/admin/feedback` y permite cambiar el estado mediante `POST /api/admin/feedback/{id}/status`. Ambos endpoints admin exigen `require_admin`.

Estados: `new`, `read`, `resolved`.

## Presencia → Admin

Para admins, el propio texto `X usuarios online` es un botón que navega al Panel de admin. Para usuarios normales sigue siendo texto informativo.

## Deployment

Una unidad muestra `+` sólo cuando su XP bancado alcanza realmente el coste de Fuerza o Velocidad. ESC o clic central cierran las fichas de unidad.
