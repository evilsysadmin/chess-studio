# V16.6ax — Técnicas tácticas + NarrativeProvider

## Técnicas especiales

Se añade una segunda capa de progresión de Combate separada de la metamorfosis.

- **Metamorfosis** decide la clase con la que una identidad despliega durante toda la batalla.
- **Técnica** es un loadout especial desbloqueado con XP propio de esa pieza y consumible una sola vez durante la batalla.
- Las técnicas se desbloquean y equipan **antes** del combate desde `Tu ejército`.
- Una técnica desbloqueada pertenece a la identidad de esa pieza: revivir conserva el desbloqueo; una baja definitiva lo pierde junto con la identidad.
- El uso se reinicia al comenzar una batalla nueva, no entre fases de un Boss.

### Primera técnica: Fuego de línea

Disponible únicamente para identidades cuyo slot original es un peón.

Requisitos:

- rango individual **Coronel** (nivel 10);
- pagar **18 XP bancado de esa pieza**.

Regla:

- una vez por batalla;
- sólo captura, no sirve como movimiento libre;
- trayectoria ortogonal como una torre;
- máximo 3 casillas;
- no atraviesa piezas;
- usa el mismo porcentaje Fuerza vs Velocidad del sistema de Combate;
- el uso se consume aunque el defensor esquive;
- no se puede activar mientras tu rey está en jaque;
- no altera las reglas de Ajedrez normal, Torneo, Práctica o Puzzles.

La legalidad de trayectoria y de dejar al propio rey seguro se delega en `chess.js` usando una torre virtual exclusivamente durante la validación. Tras resolver el ataque se restaura la clase de despliegue real de la pieza, evitando implementar un segundo motor de legalidad paralelo.

## NarrativeProvider

Se introduce `narrativeProvider.js` como frontera explícita entre **hechos del juego** y **redacción narrativa**.

El proveedor procedural es el único activo en esta versión y funciona completamente offline. Un proveedor futuro basado en mini-LLM podrá implementar `generate(event)`, pero recibirá sólo un evento saneado y limitado.

El proveedor narrativo **no puede**:

- elegir jugadas;
- modificar el tablero;
- conceder XP/rangos/medallas;
- decidir desbloqueos;
- cambiar resultados;
- ser necesario para que una batalla continúe.

Si un proveedor externo falla o devuelve basura, el sistema cae al texto procedural. Los ataques con técnicas ya usan esta capa para sus mensajes de impacto/fallo.

## Integridad adicional

Se corrige también `revivePiece`: al revivir ahora conserva el objeto completo del roster, incluida la identidad. Antes construía un objeto parcial y podía perder `identities`, contrario a la regla de que una pieza revivida sigue siendo la misma unidad.
