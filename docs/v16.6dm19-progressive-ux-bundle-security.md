# v16.6dm19 · Progressive UX, bundle visibility and API gate coverage

Small upgrade across three areas, with the same product rule: keep the common path simple and put depth behind an explicit click.

## Post-game

- `GameReportModal` is lazy-loaded only when the player asks for the report.
- The end-game action is now **Resumen de la partida**.
- The default report view shows the three core metrics and up to three distinct key moments.
- Glossary, move context, forensic timeline and CPU verdict stay under **Abrir autopsia completa**.
- Key moments are selected by a pure/tested helper so point-of-no-return and worst-move duplicates do not waste two slots.

## Bundle visibility

- `scripts/bundle_size_report.mjs` reads the real Vite `dist`, measures gzip sizes and distinguishes chunks referenced by the initial HTML from lazy chunks.
- Soft budgets only warn; they do not block CI.
- `make bundle-report` is included after the normal frontend build and CI prints the report after compiling.

## API surface hardening

- `api_surface_gate.py` now scans all production backend Python modules, including nested `APIRouter` endpoints, instead of only top-level routes from `main.py`.
- `/api/narrative` and `/api/admin/ai-metrics` are therefore part of the same general auth audit.
- The gate verifies the narrative router factory is wired with `get_current_user` and `require_admin` in `main.py`.
- Public auth routes remain explicit allowlist entries and sensitive public routes still require rate limiting.
