# V16.6am — Admin móvil legible

Esta iteración corrige el panel de administración en pantallas estrechas sin alterar el diseño de escritorio.

## Cambios

- A <= 700 px, la tabla de usuarios se transforma en fichas verticales de dos columnas.
- Usuario, actividad y acciones ocupan todo el ancho de la ficha.
- Rating, partidas, V/T/D y peor jugada se reparten en bloques legibles.
- La columna Acciones deja de ser `sticky` en móvil, evitando que tape o comprima métricas.
- Los botones de detalle/eliminación ganan altura táctil y pasan a una o dos columnas según el ancho.
- El detalle expandido utiliza una sola columna y las autopsias/tableros pueden desplazarse de forma controlada.
- Se añaden `data-label` a las celdas para que las etiquetas sigan existiendo cuando se oculta el `thead` visualmente.

## Gate

`frontend/src/adminMobileLayout.test.js` protege el contrato responsive básico: etiquetas móviles, layout de fichas y desactivación del sticky.

## Comprobación manual recomendada

Probar Admin a 360, 390 y 430 px y verificar:

1. Ningún dato queda oculto detrás de Acciones.
2. No hace falta scroll horizontal para la lista de usuarios.
3. `Ver detalles` y `Eliminar` son cómodos de pulsar.
4. Un expediente expandido cabe en una sola columna.
5. A partir de 701 px se conserva la tabla de escritorio.
