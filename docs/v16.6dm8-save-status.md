# v16.6dm8 · estado visible de guardado y conexión

## Objetivo

Hacer visible si la partida que el jugador está viendo ya está confirmada y recuperable, sin confundir actividad de CPU, hints o animaciones con persistencia real.

## Estados

- **Guardando…**: una mutación real del tablero (`playMove` / `undoMove`) está pendiente de confirmación del backend.
- **Guardado**: el backend ya confirmó el estado y el snapshot local de continuidad se escribió correctamente.
- **Sin conexión**: `navigator.onLine` informa pérdida de conectividad; tiene prioridad visual sobre el estado de escritura.
- **Error al guardar**: una escritura/mutación falló. La UI revierte al último tablero confirmado y no finge que la jugada fallida se persistió.

## Alcance

El badge se muestra durante Partida/Práctica/variantes, Torneo y durante una batalla activa de Combat Chess/Roguelike. En Combat el estado procede de su persistencia real en `combatSession/sessionStorage`, no de una llamada ficticia al backend; si `sessionStorage` falla se marca error aunque el respaldo en memoria mantenga viva la batalla hasta abandonar la página.

## UX y accesibilidad

- Badge compacto en la cabecera, fuera del tablero y del reloj.
- `role=status` + `aria-live=polite`.
- La pérdida de red se actualiza inmediatamente con eventos `online` / `offline`.
- Animación mínima sólo en `Guardando…` y desactivada con `prefers-reduced-motion`.
