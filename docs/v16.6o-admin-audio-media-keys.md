# v16.6o — Admin compacto, autopsia y audio más firme

- La tabla de Admin compacta columnas para mantener visibles las acciones.
- La columna «Peor» muestra solo el malus en cp.
- El detalle del usuario incluye autopsia de la peor jugada con incidente, piezas, origen/destino y tableros antes/después/alternativa correcta cuando hay datos suficientes.
- Backend expone los metadatos de peor jugada necesarios para reconstruir la autopsia.
- La percusión estructurada usa patrones cuantizados por familia y un reloj absoluto para evitar deriva temporal en pistas largas.
- Previous Track / Next Track del teclado se integran mediante Media Session y fallback DOM cuando el navegador expone las teclas.
- Media Session muestra el tema actual como metadata.
- adminWorstMove.test.js entra en el gate crítico local y de CI.
