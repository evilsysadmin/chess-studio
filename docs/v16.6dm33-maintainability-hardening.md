# v16.6dm33 · Hardening de mantenimiento

## Combat Chess

Las capturas probabilísticas normales quedan acotadas a **50–90%**. El cálculo de fuerza, evasión, bonus de casilla inicial y fuego concentrado no cambia; sólo cambia el límite inferior. Capturas forzadas por integridad ajedrecística y ataques del/contra rey conservan 100%.

## Doctor local

`make doctor` no instala nada ni necesita red. Comprueba runtimes, release markers, lockfiles, wiring de CI y herramientas principales. Faltas de dependencias locales o Docker se muestran como advertencias; runtimes incompatibles o estructura crítica rota fallan.

## Observabilidad

Los dashboards muestran un aviso cuando el rango tiene menos de 20 muestras HTTP o menos de 5 muestras de Workers AI. El dossier del diagnóstico SRE lleva `api_sample_quality` y `ai_sample_quality` para evitar conclusiones desproporcionadas. Las latencias API añaden referencias visuales a 300 ms y 750 ms.
