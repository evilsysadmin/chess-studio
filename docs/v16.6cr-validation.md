## Cambio principal

Combat Chess en campaña se presenta como flujo operacional explícito:

`Objetivo → Briefing → Despliegue → Combate`

- El mapa señala el siguiente paso y reduce la tira superior a datos operativos.
- El briefing tiene un único CTA principal hacia despliegue.
- Al entrar en preparación de campaña se abre automáticamente la Mesa de Guerra.
- El combate exige confirmación explícita del despliegue.
- Cerrar el deployment no confirma la fuerza.
- Bajas pendientes bloquean la confirmación aunque existan 16 unidades asignadas.
- Cambios de deployment, metamorfosis, stats o técnicas invalidan la confirmación.
- `startBattle()` mantiene un guard interno contra bypass.
- Sólo después de confirmar aparece `INICIAR COMBATE`.
- Datos secundarios y hoja de servicio pasan a un bloque desplegable.
