# v16.6dm22 · Workers AI con voz común + retrato del jugador

## Voz común

El Worker es la autoridad de estilo para las generaciones remotas. Tutea siempre, usa español de España natural, tono informal y sarcasmo juguetón de buen rollo. Puede vacilar una jugada o un dato concreto, pero no insultar la inteligencia, identidad o valor personal del jugador. Los hechos siguen siendo autoridad exclusiva de Chess Studio.

## Comentarios de partida

El pipeline no cambia: sólo eventos realmente notables pueden solicitar narrativa remota, la jugada ya debe estar confirmada y la latencia nunca bloquea tablero/reloj/persistencia. Si Workers AI falla, se conserva el comentario procedural local.

## Así te ve la CPU

`InsightsScreen` construye un dossier agregado y acotado con resultados, modos, colores usados, aperturas, rating, rachas, rivalidad, incidentes tácticos guardados, puzzles/logros y, si existe, la peor jugada ya analizada. No envía partidas completas, FEN, JWT, email ni otros secretos.

La generación usa `eventType=player_portrait`, máximo 2–4 frases, y el mismo `/api/narrative` firmado Render → Worker. La lectura local de `generateRoast()` aparece inmediatamente y actúa como fallback. La respuesta Cloudflare se cachea por una generación de tres partidas para evitar llamadas por cada visita; el usuario puede regenerarla manualmente.

El cache es derivado local, no forma parte del perfil sincronizado, y se elimina al resetear progreso o cambiar de identidad.
