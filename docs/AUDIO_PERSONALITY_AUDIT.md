# Audio personality audit

Gate de diseño del catálogo Web Audio. Cada pista debe conservar una silueta reconocible sin depender de campanitas agudas tipo “chiu-chiu”.

- Catálogo: **68 temas / 12 estilos**.
- Temas estructurados: **67/67 con huella compositiva única**.
- `andalus`: motor estocástico histórico, deliberadamente fuera del fingerprint estructurado.
- Timbres prohibidos como voces de tema: `bell`, `musicbox`.
- Normalización de arreglo: `masterTrim` limitado a **0.76–1.12**, sin compresión global.

## Criterios automáticos

`make audio-check` falla si desaparece un perfil, se repite una huella compositiva, reaparece `bell/musicbox`, se sale del rango de normalización o una pista queda demasiado corta.

- V16.6bt: el antiguo woodblock tonal 780→520 Hz se sustituyó por un golpe de madera basado en ruido filtrado a 540 Hz; el gate impide que reaparezca el barrido.
