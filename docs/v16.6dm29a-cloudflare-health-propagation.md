# v16.6dm29a · health de Workers AI resistente a propagación

El despliegue dm29 añadió el canal `analysis` a `/health`, pero el primer bucle del workflow sólo comprobaba `ok` y `service`. Durante la propagación del Worker el Custom Domain podía responder temporalmente con dm28, el bucle terminaba y el preflight estricto fallaba con `models.analysis == None`.

El hotfix hace que el propio bucle espere el routing exacto de los tres canales antes de continuar. El preflight estático también verifica que este contrato siga presente en CI.
