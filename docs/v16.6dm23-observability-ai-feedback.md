# v16.6dm23 · Observabilidad global + feedback AI con cooldown

## Observabilidad

Admin incorpora una sección **Observabilidad** con divulgación progresiva: cuatro señales útiles por defecto y detalle técnico bajo clic.

Resumen:

- API p95 de la última hora.
- porcentaje de 5xx.
- estado/latencia de persistencia Mongo.
- porcentaje de narrativas servidas por Cloudflare Workers AI.

Detalle opcional:

- uptime del proceso Render y métricas HTTP agregadas a 15 min / 1 h;
- p50/p95/p99, 4xx/5xx y rutas más activas usando patrones de ruta, nunca URLs con ids;
- ping/estado Mongo;
- usuarios, presencia, partidas y Combat agregados a partir de los datos que Admin ya carga;
- releases activas;
- Workers AI: p50/p95/p99, eventos, fallback reasons, modelo, tokens de entrada/salida, neuronas y coste estimados para la ventana reciente.

Las métricas runtime son **in-memory** y se reinician al redeploy/restart. No contienen username, FEN, jugadas, cuerpos, prompts, mensajes, cabeceras ni query strings. Cloudflare sigue siendo la fuente de verdad para consumo/billing.

## Workers AI usage

El Worker devuelve el objeto `usage` que entrega Workers AI cuando está disponible. FastAPI sólo conserva contadores técnicos agregados en su ventana acotada de telemetría.

Para `@cf/meta/llama-3.2-3b-instruct`, el Admin calcula una estimación usando la tarifa publicada por Cloudflare en agosto de 2026. Es orientativa y no sustituye el dashboard/facturación de Cloudflare.

## Así te ve la CPU

El jugador puede pedir una lectura adicional manual desde **Así juegas → Así te ve la CPU**.

- máximo una petición manual cada **6 horas**;
- el cooldown queda visible en UI y persiste localmente por usuario;
- FastAPI aplica además un cooldown server-side por identidad autenticada;
- `AI_PORTRAIT_MANUAL_COOLDOWN_SECONDS` permite ajustar el límite (default: 21600);
- la renovación automática cada 3 partidas sigue siendo independiente;
- Admin distingue `portrait_manual`, `portrait_auto` y comentarios normales en observabilidad.
