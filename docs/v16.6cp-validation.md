# v16.6cp · interacción real sobre piezas del tablero

Bug corregido:
- `.square .piece` tenía `pointer-events: none`.
- Por ello click/dblclick/hover añadidos a la imagen nunca recibían eventos.
- El navegador ejecutaba el click de la casilla; con una reserva seleccionada
  podía sustituir la unidad desplegada y aparentar "1 clic = banquillo".
- El hover tampoco podía abrir la ficha por el mismo motivo.

Solución:
- Board añade `piece-event-target` sólo cuando la pantalla suministra handlers
  explícitos de pieza o drag.
- `.piece-event-target` usa `pointer-events: auto`.
- El comportamiento histórico del Board normal permanece opt-in/no alterado.
- En Mesa de Guerra:
  - hover -> ficha rápida;
  - clic -> ficha fijada;
  - doble clic -> Banquillo;
  - drag -> recolocación.
