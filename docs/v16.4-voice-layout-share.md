# V16.4 — voz del rival + mesa alineada + compartir compacto

## VOICE: el Game Chat también habla

La síntesis de voz existente deja de ser un narrador genérico de capturas, jaques y mates. Desde esta versión hay una única fuente de verdad:

`comentario CPU → Game Chat → TTS opcional`

Por tanto, la CPU solo habla cuando ya existía una razón para escribir una entrada real en Game Chat: incidentes tácticos, comentarios de memoria/rivalidad, aperturas o resultado. No se genera una segunda colección de frases paralela.

- `VOICE ON/OFF` vive en la cabecera del **Game Chat**.
- Está **OFF por defecto** en perfiles nuevos.
- Se usa Web Speech API del navegador, sin backend, servicios externos ni audio descargado.
- Se priorizan voces `es-ES`, especialmente variantes naturales/enhanced cuando el sistema las ofrece.
- Perfil prosódico: ritmo 0.86, pitch 0.82 y volumen 0.96. La intención es sobria, pausada, docta y ligeramente afectada; la voz física exacta depende del sistema operativo.
- Cuando habla la CPU, la música ambiental baja aproximadamente al 24 % y recupera el volumen con una rampa suave al terminar. La pista no se pausa ni se reinicia.
- Hay un timeout de seguridad para restaurar el volumen si un motor TTS defectuoso no dispara `onend`.
- Al abandonar/cambiar de pantalla se cancela cualquier frase pendiente.

## Mesa de partida

En escritorio se refuerza una rejilla real de tres columnas y borde superior común:

1. mini-Winamp (220 px),
2. tablero,
3. Game Chat (270 px).

Se eliminan márgenes verticales heredados que podían dejar el reproductor visualmente más abajo que tablero/chat. A partir de 1060 px de ancho se adopta la disposición intermedia; por debajo de 820 px los tres bloques se apilan.

## Compartir

El modal de compartir pasa a un ancho máximo de 450 px y a una estructura más regular:

- cabecera centrada;
- tarjeta interior con columnas estables;
- acciones en rejilla 2×2 de botones del mismo tamaño;
- en móvil, una sola columna;
- se conserva Escape para cerrar y la generación PNG original.
