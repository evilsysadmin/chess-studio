# v16.6cm — Ficha flotante de unidad

La Mesa de Guerra sustituye el inspector lateral permanente por una ficha contextual.

- Hover/focus: vista rápida tras una pausa corta.
- Click: fija la ficha y habilita interacción cómoda con acciones.
- Reserva, Desplegados y Bajas pendientes comparten el mismo patrón.
- La ficha usa `createPortal(..., document.body)` para escapar de contenedores con scroll/overflow.
- En móvil se posiciona como panel inferior.
- El panel fijo con el rótulo `Inspector` deja de formar parte de deployment.

## Seguridad funcional

No modifica persistencia, reglas de Combat Chess, coste de revivir ni cálculo de estadísticas; sólo cambia presentación e interacción.
