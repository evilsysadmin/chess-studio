## Hook local

- `.githooks/pre-push` ejecuta `make tests` antes de cada `git push`.
- `make install` activa el hook automáticamente.
- `make tests` también lo activa de forma perezosa cuando el repo no tiene otro `hooksPath`.
- `make install-hooks` / `make hooks` permiten instalarlo explícitamente.
- La configuración usa `git config --local core.hooksPath .githooks`, por lo que solo afecta a este repositorio.
- Si el repo ya usa otro `core.hooksPath`, `make tests` avisa y no lo pisa; `make install-hooks` falla explícitamente antes de sobrescribir nada.
- Escape consciente de emergencia: `git push --no-verify`.
