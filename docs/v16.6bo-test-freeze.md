# v16.6bo — Feature-freeze + regression harness

Esta release no añade nuevas mecánicas jugables. Congela la superficie funcional de v16.6bn y refuerza su validación antes de continuar con el roadmap.

- Nuevo `make combat-smoke` para ejecutar rápidamente la batería crítica de Combat Chess.

- Checklist manual de integración en `docs/v16.6bo-manual-test-checklist.md`.
- Sin cambios de API/auth ni nuevas dependencias.

## Regla de freeze

Hasta completar el checklist manual y los gates de release, cualquier cambio debe ser bugfix, test, seguridad o UX correctiva. No se añaden sistemas nuevos.
