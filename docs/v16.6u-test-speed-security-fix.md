# v16.6u — Test speed + security bootstrap

- Trivy installer is invoked through `sh`, so a missing executable bit cannot break `make tests`.
- Security helper scripts are shipped executable anyway.
- PyJWT is upgraded from 2.10.1 to 2.13.0 to consume the fixes reported by pip-audit.
- `.venv` now tracks a hash of backend requirements and refreshes itself automatically after dependency changes.
- Backend core tests are no longer executed twice in the same quality gate.
- Test-only bcrypt cost is reduced from production 12 rounds to 4 rounds; production remains at 12 by default.
- Functional coverage is unchanged: core gate + API/profile suite still cover all backend test files.
