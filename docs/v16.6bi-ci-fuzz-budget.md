# V16.6bi — CI fuzz budget

GitHub Actions ejecutaba correctamente el fuzz de posiciones legales, pero su runner necesitaba ~6 s y Vitest aplicaba el timeout por defecto de 5 s. Localmente el mismo test terminaba en ~3.7 s.

La corrección es deliberadamente local al test pesado:

- 32 semillas, sin reducción.
- Hasta 70 plies por semilla, sin reducción.
- Timeout exclusivo: 20 s.
- El timeout global de Vitest permanece sin cambios.
- Se calcula `fen()` una sola vez por estado.
- Una posición válida no crea una assertion de Vitest; una violación lanza un error reproducible con seed, ply, FEN y errores del gate.

Así un runner lento no produce falsos rojos, mientras un test realmente bloqueado sigue teniendo un límite finito.
