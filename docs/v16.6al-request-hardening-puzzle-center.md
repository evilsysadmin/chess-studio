# v16.6al — body-limit real, puzzles imposibles y estado centrado

Micro-iteración sobre v16.6ak, sin cambiar reglas de juego.

## Seguridad API

- El límite de 1 MiB deja de confiar sólo en `Content-Length`.
- Nuevo middleware ASGI cuenta los bytes reales recibidos y rechaza con 413
  cuerpos chunked o sin longitud declarada que superen el límite.
- `Content-Length` inválido o negativo devuelve 400.
- Tests aislados cubren límite declarado, bypass chunked, replay íntegro de un
  cuerpo válido y cabeceras inválidas.
- El API surface gate exige ahora también `@limiter.limit` en todas las rutas
  públicas de identidad; `/api/health` sigue siendo la única excepción.

## Puzzles / laboratorio

- El validador detecta reyes adyacentes de forma explícita.
- Añade un presupuesto mínimo de promociones según el material vivo y los
  peones desaparecidos.
- Detecta también alfiles imposibles por color de casilla (dos alfiles del
  mismo color sin peón disponible para haber promocionado).
- El gate del banco de puzzles reutiliza este validador completo, además de
  comprobar secuencias, mates forzados y ganancia material.

## UI

- En responsive, `X online · Backend UP/DOWN` deja de forzarse a la izquierda:
  queda centrado con el reproductor global.
