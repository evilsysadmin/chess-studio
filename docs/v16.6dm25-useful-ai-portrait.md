# v16.6dm25 · Retrato AI útil, seco y con pulla

## Problema

El mismo sampling creativo usado para comentarios breves de partida estaba produciendo en `player_portrait` prosa demasiado aleatoria: nombres deformados, anglicismos, metáforas inútiles y recomendaciones difusas.

## Cambio

`player_portrait` tiene ahora una configuración de generación independiente y conservadora (`temperature 0.60`, `top_p 0.85`, 180 tokens). El prompt exige exactamente tres frases: un patrón positivo real, el principal patrón mejorable y una acción concreta para las próximas partidas.

El tono sigue siendo el de la CPU de Chess Studio: tuteo, informalidad y una pulla sarcástica breve. El sarcasmo es condimento; no puede reemplazar el análisis.

Se prohíben para el retrato las florituras largas, personajes/citas inventados, anglicismos innecesarios, saludos/despedidas y deformaciones de nombres. Si menciona una apertura debe copiar exactamente el nombre recibido en `HECHOS`.

El schema de caché pasa a v3 para que los retratos creados con el contrato anterior no sobrevivan al despliegue. Los comentarios de partida conservan su configuración creativa.
