# Daily Challenge ritual

## Goal
Make the Daily Challenge feel like a recurring castle ritual rather than another dashboard card.

## First slice
- Represent today's challenge with a diegetic castle object such as a sealed letter, parchment or auxiliary board.
- Completion changes/evolves that object for the day.
- Streak milestones may unlock visual evolution, but the challenge remains optional.
- Keep direct Daily Challenge access from Home.

## Guardrails
- No dark-pattern streak pressure.
- Missing a day does not punish unrelated progression.
- Existing daily challenge result/streak data remains authoritative.
- No fake urgency or fabricated rewards.

## Acceptance
- Date rollover and timezone behavior are deterministic.
- Completion state survives refresh/login correctly.
- Existing streak semantics are preserved.
- Mobile Home remains uncluttered and the primary play actions stay dominant.
