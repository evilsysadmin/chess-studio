# CHESSCOM Sven V43 · estudio de cabeza original

La referencia visual canónica es el PNG **Operación Dust Veil: Chesscom**
fijado en [el contrato V41](chesscom-golden-art-v41.json). V42 quedó
rechazada visualmente; sus ocho renders parecían un maniquí. Esta iteración
**no recupera ese cuerpo**.

Se modela únicamente el bust de Sven, de forma original en Blender, con
superficies anatómicas de sección variable para cara, balaclava y casco;
ranura real de ojos, NVG plegado, casco con reborde, auriculares, antena
de micrófono, tela rugosa y cowl. Hay ocho vistas reales a 320×320 y fuentes
`.blend` / `.glb` como artifact efímero de CI.

**No es un personaje terminado.** No se declara rig corporal, 96 frames,
contacto de manos/fusil o compatibilidad con runtime. Sólo habrá promoción
tras inspección de las ocho vistas frente al PNG canónico a tamaño HUD real.
La PR visual queda en Draft sin automerge mientras esa revisión esté pendiente.
Si este bust falla, se descarta: CI verde no equivale a calidad artística.
