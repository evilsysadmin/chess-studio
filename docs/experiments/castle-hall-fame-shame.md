# Castle Hall of Fame / Hall of Shame

## Goal
Create two diegetic castle galleries that archive genuinely notable achievements and disasters from real play.

## First slice
- Define Fame and Shame entry schemas with evidence/provenance.
- Curate only high-signal incidents; routine games do not get plaques.
- Render galleries as physical castle spaces/objects rather than dashboard lists.
- Allow replay/review navigation from an entry when the source game still exists.

## Fame candidates
Brilliant tactics, difficult wins, major comebacks, long streak milestones and legendary Combat veterans.

## Shame candidates
Missed mate, allowed mate, queen lost to pawn, catastrophic stalemate, absurd material loss and historically bad collapses.

## Guardrails
- Humor remains playful, never fabricates a failure.
- Bounded archive with deduplication.
- Deleting/resetting source progress removes dependent gallery entries predictably.

## Acceptance
- Evidence-backed classification tests.
- No duplicate plaque from the same incident.
- Mobile gallery remains navigable.
- Default Home remains uncluttered.
