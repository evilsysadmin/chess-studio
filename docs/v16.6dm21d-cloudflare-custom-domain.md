# v16.6dm21d · Cloudflare Worker Custom Domain

## Objetivo

Publicar el narrador Workers AI únicamente en:

```text
https://ai.shadowops.dpdns.org
```

La zona `shadowops.dpdns.org` ya está delegada/gestionada por Cloudflare. El
Custom Domain de Workers se encarga del routing DNS y del certificado TLS; no
se crea un CNAME manual hacia `workers.dev`.

## Terraform

`infra/cloudflare/main.tf` gestiona tres piezas:

1. `cloudflare_workers_script.narrative_ai`
2. `cloudflare_workers_script_subdomain.narrative_ai` con `enabled=false`
3. `cloudflare_workers_custom_domain.narrative_ai` para
   `ai.shadowops.dpdns.org`

El secreto HMAC continúa fuera del state y se instala después del apply con
`wrangler secret put`.

## GitHub Actions

El runner sigue siendo efímero, así que antes de `plan` consulta Cloudflare:

- importa el Worker si ya existe;
- importa la configuración workers.dev si existe;
- consulta `/accounts/{account}/workers/domains?hostname=...` e importa el
  Custom Domain por `<account_id>/<domain_id>` si ya existe;
- aborta si `ai.shadowops.dpdns.org` está asociado a otro Worker en vez de
  apropiárselo silenciosamente.

Después del apply instala el secreto, valida el Custom Domain y prueba:

```text
GET https://ai.shadowops.dpdns.org/health
```

La primera emisión/propagación TLS puede tardar más que un deploy normal; el
workflow reintenta hasta cinco minutos mostrando HTTP/TLS en vez de esconder el
fallo bajo `curl -f`.

## Secrets

No hay secretos nuevos.

GitHub Actions conserva:

```text
CLOUDFLARE_API_TOKEN
CLOUDFLARE_ACCOUNT_ID
CHESS_AI_SHARED_SECRET
```

Render conserva/añade:

```text
AI_NARRATIVE_ENABLED=true
CF_AI_WORKER_URL=https://ai.shadowops.dpdns.org
CHESS_AI_SHARED_SECRET=<mismo valor que GitHub>
CF_AI_TIMEOUT_SECONDS=12
```

`CLOUDFLARE_API_TOKEN` no se copia a Render.
