# v16.6l — quality gate local autocontenido

- `make tests`, `make tests-fe` y `make tests-be` preparan automáticamente las dependencias si faltan.
- Frontend usa el Vitest local fijado por `package-lock.json`; no usa `npx` para descargar una versión al vuelo.
- Backend usa una `.venv` local del repo para evitar contaminar o depender del Python del sistema.
- Los targets individuales (`gate-core`, `test-backend`, `frontend-build`, etc.) son también autocontenidos.
- GitHub Actions sigue siendo el quality gate remoto antes del deploy a Pages.
