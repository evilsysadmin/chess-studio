# v16.6ba — Combat Chess

La campaña antes presentada como «Combate Roguelike» adopta **Combat Chess** como nombre visible.

- **Combat Chess** es la marca del modo de campaña persistente.
- **Roguelike militar** queda como descriptor del género.
- Los identificadores internos (`roguelike`, claves de storage, nombres de módulos) se conservan para no romper partidas guardadas ni migraciones.
- La Torre, veteranos, rangos, medallas, metamorfosis, Memorial, boss HP y compensación de amenaza siguen siendo las mismas mecánicas.
- Historial y diagnóstico distinguen ahora correctamente una batalla de Combat Chess de una batalla libre de Combate.

Lema visible: **«Forma tu ejército. Haz veteranos. Rompe las reglas. Sobrevive.»**
