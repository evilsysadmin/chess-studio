# v16.6ak — Release hardening, clocks, series, training, fuzz y E2E

Esta iteración consolida el backlog de fiabilidad/producto sin añadir nuevos modos de juego.

## Toolchain y supply chain

- Vite sube a 6.4.3; `@vitejs/plugin-react` queda alineado en 4.7.0.
- El Dockerfile frontend usa Node 22, igual que CI.
- `trivy fs` incluye dependencias de desarrollo.
- Nuevo `make security-images`: construye y escanea las imágenes frontend/backend reales.
- Nuevo `make security-full`: filesystem/dependencias/API + imágenes Docker.
- Nuevo `make release-gate`: tests + security + imágenes Docker + Playwright.
- En CI, Docker/Playwright solo arrancan tras los gates básicos verdes.
- Los jobs de Trivy comparten la misma caché de base de vulnerabilidades.

## Laboratorio

- Validación más estricta de FEN y posiciones: reyes, número de piezas/peones,
  peones en filas imposibles, derechos de enroque y en-passant coherentes.
- Cambiar manualmente el turno elimina un en-passant histórico incompatible.
- Fuzz frontend comprueba posiciones surgidas de partidas legales aleatorias.

## Relojes

- Persistencia por `gameId` para sobrevivir a refresh.
- Se descuenta el tiempo real transcurrido si sigue moviendo el mismo color.
- Detecta bandera durante el refresh.
- El control de tiempo se recupera al continuar una partida.
- Snapshots terminados/abandonados se limpian y no sobreviven a un cambio de cuenta.
- Fuzz de estados de reloj comprueba no crear tiempo ni valores negativos.

## Series BO3/BO5

- Validación del estado persistido.
- Deduplicación por `gameId` para no contar dos veces la misma partida.
- Resultado desconocido se rechaza; no se convierte silenciosamente en tablas.
- Fuzz determinista de series y tests de estado corrupto.

## Memoria CPU y entrenamiento personal

- La CPU recuerda marcador y resultado anterior de una serie.
- Puede citar ocasionalmente la última partida real (resultado/apertura/duración).
- Los puzzles nacidos de errores guardan intentos, soluciones y soluciones limpias.
- Un fallo sigue haciendo que el intento no sea "limpio" aunque se proteja la racha con puntos.
