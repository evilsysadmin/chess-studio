# V15.4 — Admin insights + música por sesión + Cairo 00:47

## Admin: “Así juega”

La consulta del informe ya no mete el username en el path. El frontend usa `POST /api/admin/user-insights` con `{ "username": "..." }` y JWT de admin. Esto evita 404 causados por caracteres reservados en nombres heredados y mantiene el endpoint GET anterior como compatibilidad.

El panel deja de reintentar en bucle cuando una consulta falla: muestra el error real y un botón **Reintentar informe**.

## Música por sesión

El tema musical deja de formar parte del perfil sincronizado. Cada login/registro exitoso sortea una pista del catálogo y la guarda en `sessionStorage`. La elección manual dura sólo esa sesión. Un login nuevo vuelve a sortear. Los mutes de Música/FX sí siguen siendo preferencias persistentes.

## Cairo 00:47

Vigésimo tema original. Jazz árabe nocturno y relajado con qanun sintético, voz de metal apagado, Rhodes, contrabajo y escobillas. Usa cuatro secciones de 64 pasos y una forma larga de más de cinco minutos antes de repetir exactamente el mismo arreglo.

No copia melodías ni estructura de ninguna referencia externa; sólo comparte rasgos de alto nivel como el cruce de jazz nocturno, color modal árabe, tempo relajado y espacio entre frases.
