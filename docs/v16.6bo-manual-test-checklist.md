# v16.6bo — Checklist manual de feature-freeze

Objetivo: probar la integración completa antes de añadir más mecánicas. Registrar cada fallo con pantalla, pasos, resultado esperado/real y, si existe, consola/traceback.

## 0. Gate antes de abrir el navegador

- [ ] `make combat-smoke`
- [ ] `make tests`
- [ ] `make security-full` si se va a publicar una release
- [ ] `make e2e` o `make release-gate` antes de desplegar

## 1. Login, sesión y navegación

- [ ] Login correcto y carga completa del perfil.
- [ ] Música permanece apagada en login y arranca tras autenticar.
- [ ] ESC y clic derecho vuelven/cierran donde corresponde.
- [ ] Logout limpia estado efímero sin mezclar el siguiente usuario.

## 2. Combat Chess — inicio y continuidad

- [ ] Iniciar Combat Chess libre y campaña.
- [ ] Hacer varios movimientos/capturas sin volver espontáneamente al setup.
- [ ] Recargar la pestaña durante una batalla: reanuda la misma batalla.
- [ ] Una sesión de otra misión/nodo no restaura la batalla equivocada.
- [ ] Finalizar/retirarse limpia el snapshot activo.

## 3. Deployment 2.0

- [ ] Tablero muestra sólo la formación propia, no un ejército rival ficticio.
- [ ] Click/tap coloca una unidad en un slot compatible.
- [ ] Drag/drop coloca una unidad en un slot compatible.
- [ ] Un intento incompatible rebota/no modifica la formación.
- [ ] El Rey permanece en su puesto fijo.
- [ ] Sustituir una unidad devuelve la anterior a reserva.
- [ ] Buscar por alias funciona.
- [ ] Filtros por tipo/estado funcionan.
- [ ] Orden por rango/nivel/tipo/nombre funciona.
- [ ] `Auto · veteranos` prioriza unidades con servicio.
- [ ] `Auto · reclutas` prioriza unidades menos valiosas.
- [ ] No se puede iniciar con formación incompleta.
- [ ] Amenaza total cambia sólo con las unidades desplegadas.

## 4. Roster >16 y reservas

- [ ] Obtener un refuerzo aumenta el barracón a 17+.
- [ ] Repetir el mismo hito no farmea el mismo refuerzo.
- [ ] Reserva conserva alias, identidad, XP, rango, medallas y expediente.
- [ ] Una reserva no desplegada no gana batalla/XP/medallas.
- [ ] Una reserva no desplegada no puede morir por esa batalla.
- [ ] Desplegar una reserva sí la convierte en participante real.
- [ ] Muerte permanente de reserva crea sustituto nivel 1 con identidad nueva.

## 5. Metamorfosis

- [ ] Sólo aparecen formas realmente desbloqueadas.
- [ ] La forma se elige antes de batalla y queda fijada durante el encuentro.
- [ ] `Base: Peón → Forma: Caballo` se entiende visualmente.
- [ ] Un peón metamorfoseado sigue ocupando slot de peón.
- [ ] En batalla se mueve/captura según su forma desplegada.
- [ ] Tras el combate conserva la misma identidad/expediente de peón.

## 6. Campaña XCOM-lite e inteligencia

- [ ] Mapa ofrece únicamente nodos conectados válidos.
- [ ] Seleccionar combate abre briefing antes de deployment.
- [ ] Sin intel no aparece la dificultad exacta.
- [ ] Contacto revela rango de amenaza.
- [ ] Evaluación revela dificultad exacta + modificador.
- [ ] Dossier revela descripción completa y HP del boss cuando corresponde.
- [ ] Comprar intel descuenta créditos una sola vez y respeta saldo.
- [ ] No se puede comprar intel después de aceptar briefing/iniciar batalla.
- [ ] No se puede comprar intel para un nodo distinto al seleccionado.
- [ ] Victoria normal/élite/boss concede créditos correctos una sola vez.
- [ ] Eventos recon/salvage afectan sólo al siguiente combate según regla.
- [ ] Campaña v1 existente migra a v2 sin perder ruta/progreso.

## 7. Rangos, medallas y servicio

- [ ] Batalla participada incrementa servicio sólo de desplegados.
- [ ] Kills se atribuyen a la identidad correcta.
- [ ] Supervivencias y rachas se actualizan correctamente.
- [ ] Rangos sólo suben al cumplir condiciones reales.
- [ ] Medallas se otorgan una sola vez al cumplir su condición.
- [ ] Daño/finalización de boss se atribuyen a la unidad correcta.
- [ ] Renombrar cambia alias sin crear identidad nueva.

## 8. Muerte, revive y Memorial

- [ ] Unidad caída abre su ventana de revive antes de la próxima batalla.
- [ ] Revivir conserva exactamente identidad, expediente y progresión.
- [ ] Empezar la siguiente batalla sin revivir archiva la identidad.
- [ ] Memorial muestra la unidad caída con su historial real.
- [ ] Sustituto recibe alias/identityId nuevos y empieza nivel 1.
- [ ] Recluta nivel 1 no revivable sigue pasando por Memorial antes del reemplazo.

## 9. Boss HP

- [ ] HP sólo existe en el Rey boss, nunca en partidas normales.
- [ ] Boss empieza con 5 HP.
- [ ] Daño sólo se aplica según reglas de jaque/mate del modo.
- [ ] Jaque contra el humano no daña al boss.
- [ ] Fases cambian en 5–4 / 3–2 / 1 HP.
- [ ] Llegar a 0 HP resuelve correctamente la victoria de campaña.

## 10. Tutoriales no estándar

- [ ] Primera entrada a una mecánica nueva puede abrir tutorial contextual.
- [ ] Se puede saltar sin bloquear el modo.
- [ ] Botón `?` permite reabrirlo después.
- [ ] Progreso se guarda por usuario.
- [ ] Combat Chess, Deployment, Metamorfosis, Campaña, Intel, Torneo, reglas especiales, Puzzles/Daily, Rival Fantasma, Así juegas, Laboratorio y Espectador tienen tutorial.
- [ ] El índice `Modos especiales` los lista de forma comprensible.

## 11. Regresión fuera de Combat Chess

- [ ] Partida rápida estándar sigue siendo ajedrez normal.
- [ ] CPU mantiene dificultad razonable en niveles existentes.
- [ ] Torneo inicia/finaliza y actualiza progresión.
- [ ] Puzzles cargan posiciones legales y soluciones válidas.
- [ ] Daily Challenge mantiene su estado propio.
- [ ] Así juegas sólo muestra conclusiones basadas en datos almacenados.
- [ ] Replay e historial abren partidas existentes.
- [ ] Series y reloj siguen funcionando.
- [ ] Zen mode y audio no rompen navegación.

## 12. Admin y privacidad

- [ ] Tarjeta Admin sólo aparece para admins.
- [ ] Usuarios online se muestran correctamente.
- [ ] Actividad gruesa muestra etiquetas permitidas (Combat Chess, Torneo, etc.).
- [ ] Actividad NO expone FEN, movimientos, rival, chat ni contenido privado.
- [ ] Contador público de online sigue excluyendo admins.
