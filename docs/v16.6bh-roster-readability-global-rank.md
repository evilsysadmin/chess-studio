# V16.6bh — Orden de batalla legible + rango global explícito

## Orden de batalla

- El roster de 16 unidades usa 6 columnas en escritorio: 6 + 6 + 4, con la última fila centrada.
- Las tarjetas son más anchas y la tarjeta completa abre el expediente; se elimina el texto redundante `Expediente →`.
- El alias deja de forzarse a una sola línea y gana prioridad visual.
- Cada ficha compacta muestra pieza, rango/nivel, estado y servicio; el detalle completo sigue en el modal.
- Tablet conserva 4 columnas y móvil 2.

## Carrera global

- `Soldado`, `Cabo`, `Sargento`, etc. se etiquetan explícitamente como **Rango global de campaña/carrera**.
- Una nota aclara que ese rango pertenece al perfil de Combat Chess y no corresponde a ninguna de las 16 unidades.
- Los rangos individuales permanecen en el Orden de batalla y en cada expediente.
