# v16.6k — quality gate local con Make

Antes de hacer push se puede ejecutar el mismo conjunto de comprobaciones funcionales que usa CI:

- `make tests`: frontend + backend completos.
- `make tests-fe` o `make tests/fe`: gate crítico frontend, suite completa y build.
- `make tests-be` o `make tests/be`: gate del core backend, suite completa y `pip check`.
- `make test`: alias histórico de `make tests`.
- `make quality-gate`: alias explícito de `make tests`.

El gate crítico frontend incluye también `src/puzzles.test.js`, igual que `.github/workflows/ci.yml`.

Las dependencias no se reinstalan en cada ejecución local; usar `make install` cuando sea necesario. GitHub Actions sigue haciendo su instalación limpia (`npm ci` / `pip install`) y actúa como quality gate independiente antes del deploy.
