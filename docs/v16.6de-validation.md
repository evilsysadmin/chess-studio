## Limitaciones del runtime

No hay `node_modules`, Chromium ni acceso de red, por lo que aquí no se pueden ejecutar:

- Vitest completo con `@vitest/coverage-v8`;
- Playwright/Chromium;
- backend completo con todas las dependencias del proyecto.

GitHub Actions ejecutará esos gates y será la autoridad final del baseline de coverage.
Los thresholds son deliberadamente un ratchet inicial: si el baseline real los supera
con margen, deben aumentarse de forma incremental en próximas iteraciones.
