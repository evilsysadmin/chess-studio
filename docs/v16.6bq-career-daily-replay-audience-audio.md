# v16.6bq — Career visuals + Daily + Replay + Audience + Audio

Esta release amplía lectura, continuidad diaria y ambientación sin cambiar reglas de ajedrez ni el núcleo de Combat Chess.

## Carrera: datos visibles, no inventados

- Perfil RPG derivado únicamente de métricas realmente almacenadas: Accuracy media, conversión de ventajas >= +3.0, posiciones <= -3.0 salvadas, incidentes medidos bajo presión y porcentaje de enroque.
- Los atributos incluyen tamaño de muestra y se rotulan como índices derivados, no como ELO ni diagnóstico de habilidad.
- Tres heatmaps 8×8 construidos desde el historial real: actividad de destinos, casillas donde capturas y casillas donde pierdes piezas.
- Sin datos suficientes se muestra ausencia de muestra; no se generan fortalezas o debilidades ficticias.

## Daily Challenge

- Calendario visual de los últimos 28 días.
- Corrección de la racha actual: una racha antigua ya no aparece como activa tras varios días sin resolver el Daily.
- `bestStreak` histórico se conserva.
- Logros reales para 3, 7 y 30 días de mejor racha.

## Replay · Director's Cut

- Velocidad 0.5×, 1× y 1.75×.
- Capítulos clicables para errores y blunders detectados por el análisis existente.
- Navegación anterior/siguiente entre momentos críticos.

## Grada anónima

- Las reacciones sólo se consideran para eventos que el detector ya marcó como notables.
- En cada evento el router determina de forma estable: CPU, público, ambos o silencio.
- Se mantiene una proporción importante de silencio para evitar comentarios constantes.
- Las líneas dependen del evento real (mate, mate perdido, horquilla, brocheta, promoción, dama comida por peón, etc.).
- Zen mode sigue suprimiendo la presentación ambiental.

## Música

El catálogo pasa de 56 a 60 pistas y de 6 a 8 grupos visibles:

- Lo-Fi / Chill: `Lo-fi · lluvia en cassette`, `Lo-fi · ventana encendida`.
- Synthwave: `Synthwave · caballo de neón`, `Synthwave · arcade 02:17`.

Cada una usa una familia estructurada propia y se mantiene la regla de sesión: selección aleatoria tras autenticar, continuidad automática y no repetición inmediata de la pista que acaba de sonar.

## Gates

`make audio-check` valida 60 pistas / 8 estilos. `make data-ux-check` añade 9 invariantes offline para heatmaps, perfil RPG, calendario/racha Daily y routing de la grada. `make static-preflight` ejecuta ambos y sigue funcionando sin npm, Docker ni red.
