# V16.6cg — Workers AI integrado y Admin directo

## Narrativa remota

- El navegador llama únicamente a FastAPI autenticado.
- FastAPI firma el dossier factual y llama al Worker de Cloudflare.
- El modelo no recibe autoridad sobre jugadas, resultados, XP, rating ni estado del juego.
- Kill switch, circuit breaker, rate limiting, timeout y grounding mantienen el servicio opcional.
- `GameScreen` dispara la narrativa después de la jugada y sin `await` en el camino crítico.
- Un `provider=local` del backend se trata como remoto no disponible para conservar el comentario procedural rico que ya existía en el frontend.

## Admin

- El nombre de usuario es ahora el control accesible que abre/cierra el expediente (`aria-expanded` + `aria-controls`).
- El botón “Ver detalles” desaparece; Acciones queda reservada para eliminación de cuenta.
- Fechas y horas se formatean mediante `adminFormatting.js` con `es-ES`, `hour12: false` y formato visible `dd/mm/aaaa · HH:mm:ss`.
- La tarjeta de métricas AI muestra estado, porcentaje Cloudflare/fallback, p95 y breaker sin guardar prompts ni textos.

## Gates

- `make ai-contract` cubre provider, API, seguridad de navegador, Worker y wiring remoto.
- Los contratos de Admin protegen usuario clicable, ausencia de “Ver detalles” y timestamps 24h.
- La suite completa del repo sigue siendo la autoridad de regresión final.
